# C 语言作业 · 第 1–5 题

> **仓库地址**：<https://github.com/185207911/c-homework>

本仓库收录 C 语言入门作业的 5 道题，全部为单文件程序，每题一个 `.c` 文件，放在仓库根目录。

## 题目与文件

| 文件 | 题目 | 输入示例 | 输出示例 |
| --- | --- | --- | --- |
| [`1_main.c`](1_main.c) | 摄氏度转华氏度，`F = C * 9 / 5 + 32` | `100` | `华氏温度 = 212.0` |
| [`2_main.c`](2_main.c) | 判断实数正负零 | `-3.5` | `负数` |
| [`3_main.c`](3_main.c) | 判断三条边能否构成三角形 | `3 4 5` | `能构成三角形` |
| [`4_main.c`](4_main.c) | 百分制成绩转等级 A–E | `85` | `B` |
| [`5_main.c`](5_main.c) | 简易四则运算器 | `3 + 5` | `8.00` |

## 编译与运行

需要 gcc（MinGW / Dev-C++ 自带的都可以）。

```bash
# 单个编译
gcc 1_main.c -o 1_main.exe -Wall -Wextra

# 一次全部编译（Windows PowerShell）
./build.ps1
```

运行示例：

```text
$ ./1_main.exe
100
华氏温度 = 212.0
```

## 几个实现细节

- 每个 `.c` 文件的前两行是 `// 学号` 与 `// 姓名` 注释，供自动评测识别身份。
- 所有输入都用 `scanf` 的返回值做了校验，输入不合法时输出 `输入无效` 并返回 1，避免脏数据往下算。
- 程序只向标准输出打印结果，不打印任何交互提示语，方便自动评测按行比对。
- `2_main.c` 里修正了原稿 `scanf(" %f ", &x)` 的问题：格式串末尾的空格会让程序一直等待非空白字符，改成 `scanf("%f", &x)`。
- `5_main.c` 除数为 0 时单独报错，不会出现除零。
- 浮点字面量统一写成 `9.0f / 5.0f`，避免 `double` 隐式转换带来的告警。
